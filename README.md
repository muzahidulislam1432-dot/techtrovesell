# TechTroveSell — Phase 1

A fast, responsive Astro homepage for a technology product-review and buying-guide website.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local address shown in the terminal.

## Build for Cloudflare Pages

```bash
npm run build
```

Cloudflare Pages settings:

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js version: 20 or newer

## Phase 1 contents

- Responsive homepage
- Reusable site header and footer
- Reusable product and article cards
- Mobile navigation
- Original SVG placeholder artwork
- SEO title, description, canonical URL, Open Graph tags
- Amazon affiliate disclosure in the footer

Replace placeholder links and product artwork only with content and media you are authorized to use.
