# TechTroveSell Premium

A premium Astro foundation for an Amazon affiliate review and buying-guide website.

## Included

- Responsive homepage
- Reviews and dynamic review pages
- Buying guides and dynamic guide pages
- Category pages
- Live client-side search
- Breadcrumbs
- Basic JSON-LD schema
- Open Graph and Twitter metadata
- Sitemap and robots.txt
- Affiliate disclosure
- About, Contact, Privacy Policy and Affiliate Disclosure pages

All product content is sample content. Replace it with researched information and approved Amazon affiliate links.

## Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`

## Update workflow

1. Replace the files in your local GitHub repository with this package.
2. Commit the changes.
3. Push to `main`.
4. Cloudflare Pages will redeploy automatically.
