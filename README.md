# TechTroveSell — Final Version

A stable Astro foundation for an Amazon affiliate review and buying-guide website.

## Included

- Responsive premium homepage
- Review archive and dynamic review pages
- Buying-guide archive and dynamic guide pages
- Working category routes
- Live client-side search
- Breadcrumbs
- Basic JSON-LD structured data
- Open Graph and Twitter metadata
- Complete sitemap for included routes
- `robots.txt`
- Affiliate disclosure
- About, Contact, Privacy Policy and Affiliate Disclosure pages

## Important

The included product entries are sample content. Replace them with researched information, authorized images and approved Amazon affiliate links before promoting the site.

## Cloudflare Pages settings

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

## Upload workflow

1. Extract this ZIP.
2. Replace the existing files in your GitHub repository.
3. Commit to `main`.
4. Cloudflare Pages will deploy automatically.
